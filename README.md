# matelot-cloud/.github

Organization-level defaults for the `matelot-cloud` GitHub organization:

- `profile/README.md` — the organization profile shown at https://github.com/matelot-cloud.
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md` — default community health files; GitHub applies them to every
  public repository of the organization that has no file of its own (website, helm-charts). `matelot-cloud/matelot`
  carries its own copies (the canonical ones) — keep them identical.
- No `FUNDING.yml` on purpose: sponsorship buttons are off.

Changes here are made by hand (this repository is not written by the release pipeline).
